# 양승훈 포트폴리오

임베디드 AI · 영상처리 · 게임 개발. GitHub Pages로 배포하는 개인 포트폴리오 사이트입니다.

## 구조

```
content/   사이트 내용 (JSON) — 업데이트는 여기만 고치면 됩니다
assets/    이미지, GIF, 연구 자료 그림
```

내용 수정 방법은 [content/README.md](content/README.md), 확인이 필요한 항목은 [content/REVIEW.md](content/REVIEW.md)에 있습니다.
